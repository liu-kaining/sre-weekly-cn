# DevOps 指南单页 HTML 实现与验收

**目标：**把已确认的 15 份 Markdown 完整呈现为可独立打开、可离线阅读的单页 HTML。

**内容依据：**上级目录 README 及 01—14 章。原始 Markdown 保持为内容源。

**视觉方向：**暖白纸面、墨色正文、陶土橙强调色；编辑式封面、交付链路导航、长文阅读版式。中文标题采用本地宋体系列，正文采用本地中文无衬线字体，无外部字体请求。

**技术方案：**构建时使用仓库已有的 Astro Markdown 处理器与 Cheerio，输出静态正文；内嵌 CSS、普通 JavaScript 和 SVG。运行时不请求其他资源。

## 文件职责

| 文件 | 用途 |
|---|---|
| `build.mjs` | 读取 15 份内容、渲染、处理锚点、生成搜索数据与 HTML |
| `template.html` | 页面外壳、封面、导航和辅助控件 |
| `styles.css` | 阅读版式、响应式、暗色和打印样式 |
| `reader.js` | 搜索、目录、阅读位置、已读、主题、代码复制 |
| `build.test.mjs` | 检查正文完整、锚点有效、无运行时外部资源 |
| `browser_test.py` | 浏览器验证搜索、导航、移动端、离线、持久化与无 JS 阅读 |
| `../index.html` | 最终可分享的单文件 |

## 执行顺序

1. 先运行尚未实现的构建测试，确认缺失单页功能会失败。
2. 实现生成器：所有正文静态输出，原始图示转为内嵌图形并保留源码。
3. 制作阅读界面：完整目录、流程导航、正文、章内目录、搜索、进度、暗色与打印。
4. 运行生成与完整性检查：

   ```sh
   node docs/devops-platform-guide/web/build.mjs
   node --test docs/devops-platform-guide/web/build.test.mjs
   ```

5. 用 Python Playwright 和本机 Chrome 直接打开 `file://` HTML，验证交互并截图。
6. 复查桌面与手机视觉、超长表格／代码、无网络和无 JS 阅读，修复发现的问题。

## 验收条件

- 全部 15 份正文可读，表格、代码、列表、引用和原始图示信息保留。
- 原始文档之间的链接变成页内锚点；锚点唯一且可定位。
- 搜索可查正文并跳转，键盘可打开和关闭搜索。
- 桌面目录、手机目录、章内目录与滚动进度正常。
- 已读状态和主题可保存；存储不可用时不影响阅读。
- 手机页面无整体横向溢出，长表格与代码在局部滚动。
- HTML 中不引用外部脚本、样式、字体、图片或图示服务。
- 禁用 JavaScript 仍可阅读全部正文。
- 浏览器无未捕获错误；打印输出正文，隐藏操作界面。
